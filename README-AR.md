# سينما بلاس — دليل التشغيل السريع

مشروع **سينما بلاس** (Cinema Plus) — موقع سينما بواجهة عربية RTL مبني بـ **Laravel 13 + Filament 5**.
واجهة الأفلام العامة مع حجز التذاكر، ولوحة تحكم كاملة لإدارة المحتوى.

---

## المتطلبات

- PHP **8.3** أو أحدث مع الإضافات: `pdo_sqlite`، `mbstring`، `openssl`، `fileinfo`، `intl`، `zip`
- [Composer](https://getcomposer.org) الإصدار 2
- SQLite (مضمّن في PHP عادةً — لا يحتاج خدمة منفصلة)

> ملف `composer.lock` مُثبَّت ليعمل على **PHP 8.3** (Symfony 7.4). يعمل أيضًا على PHP 8.4/8.5.

## التشغيل

```bash
# 1) ثبّت الاعتماديات (مجلد vendor غير مضمّن في الملف المضغوط)
composer install

# 2) اربط مجلد التخزين العام (يعرض صور الأفلام تحت /storage)
php artisan storage:link

# 3) شغّل الخادم
php artisan serve --port=8000
```

ثم افتح: <http://localhost:8000>

> قاعدة البيانات (`database/database.sqlite`) **جاهزة ومُعبّأة مسبقًا** (12 فيلمًا، 3 باقات، أوقات العرض، 68 دولة).
> لإعادة التعبئة من الصفر: `php artisan migrate:fresh --seed`

## لوحة التحكم

- الرابط: `/admin`
- المستخدم: `admin@cinema.test`

### الواجهات المتاحة في اللوحة

| الواجهة | الحقول |
|---|---|
| **الباقات** | اسم الباقة · عدد المقاعد · ماذا تشمل |
| **فئات الأفلام** | اسم الفئة |
| **الأفلام** | الاسم · الصورة · الفئة · الوصف · المدة · التقييم · عدد المُقيّمين · التصنيف العمري · الحالة (معروض/قريبًا) · الشارة · ألوان البطاقة · أيقونة العرض القادم · **سعر التذكرة لكل باقة** |
| **أوقات العرض** | اليوم · الفيلم · وقت البداية والنهاية (8 عروض لكل فيلم يوميًا) |
| **حجز التذاكر** | عرض الحجز + تأكيد الدفع + تأكيد الحضور |

## ملاحظات مهمة

- ملف `.env` مضمّن مع `APP_KEY` جاهز — لا حاجة لتشغيل `php artisan key:generate` إلا إن أردت مفتاحًا جديدًا.
- إن رفعت الموقع خلف **بروكسي HTTPS**، فالبروكسي موثوق به مسبقًا (`trustProxies`) لتوليد روابط الأصول على https تلقائيًا.
- الصور الأصلية للتصميم محفوظة في `Movies_extracted/Movies/` للمراجعة.
